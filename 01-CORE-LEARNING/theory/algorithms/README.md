# 🧮 Algorithms (Thuật toán)

## Tổng quan
Phần này chứa các thuật toán từ cơ bản đến nâng cao, được sắp xếp theo mức độ khó và tính ứng dụng.

## 📚 Danh sách chủ đề

### 1. Basic Algorithms (Thuật toán cơ bản)
- **Linear Search**: Tìm kiếm tuần tự
- **Binary Search**: Tìm kiếm nhị phân
- **Two Pointers**: Kỹ thuật hai con trỏ
- **Sliding Window**: Cửa sổ trượt
- **Prefix Sum**: Tổng tiền tố

### 2. Sorting Algorithms (Thuật toán sắp xếp)
- **Comparison-based**:
  - Bubble Sort (O(n²))
  - Selection Sort (O(n²))
  - Insertion Sort (O(n²))
  - Merge Sort (O(n log n))
  - Quick Sort (O(n log n) trung bình)
  - Heap Sort (O(n log n))
- **Non-comparison based**:
  - Counting Sort
  - Radix Sort
  - Bucket Sort

### 3. Searching Algorithms (Thuật toán tìm kiếm)
- **Linear Search**: O(n)
- **Binary Search**: O(log n)
- **Ternary Search**: O(log n)
- **Exponential Search**: O(log n)

### 4. Graph Algorithms (Thuật toán đồ thị)
- **Traversal**:
  - Depth First Search (DFS)
  - Breadth First Search (BFS)
- **Shortest Path**:
  - Dijkstra's Algorithm
  - Bellman-Ford Algorithm
  - Floyd-Warshall Algorithm
- **Minimum Spanning Tree**:
  - Kruskal's Algorithm
  - Prim's Algorithm
- **Advanced**:
  - Topological Sort
  - Strongly Connected Components
  - Bipartite Matching

### 5. Dynamic Programming (Quy hoạch động)
- **Classical Problems**:
  - Fibonacci Sequence
  - Longest Common Subsequence
  - Longest Increasing Subsequence
  - Knapsack Problem (0/1 và Unbounded)
  - Edit Distance
- **Advanced DP**:
  - DP on Trees
  - Digit DP
  - Bitmask DP
  - Matrix Chain Multiplication

### 6. Greedy Algorithms (Thuật toán tham lam)
- **Activity Selection**
- **Fractional Knapsack**
- **Huffman Coding**
- **Job Scheduling**
- **Minimum Coins**

### 7. Divide and Conquer (Chia để trị)
- **Merge Sort**
- **Quick Sort**
- **Binary Search**
- **Maximum Subarray (Kadane's)**
- **Closest Pair of Points**

### 8. String Algorithms (Thuật toán chuỗi)
- **Pattern Matching**:
  - Naive Pattern Matching
  - KMP Algorithm
  - Rabin-Karp Algorithm
  - Z Algorithm
- **String Processing**:
  - Manacher's Algorithm (Palindrome)
  - Suffix Array
  - LCP Array

## 📖 Cách học
1. **Hiểu lý thuyết**: Đọc và hiểu nguyên lý hoạt động
2. **Phân tích độ phức tạp**: Time và Space complexity
3. **Implementation**: Code từ scratch
4. **Practice**: Giải bài tập trên các platform
5. **Optimize**: Tối ưu hóa code

# 🎯 01-CORE-LEARNING - Học tập cốt lõi Competitive Programming

> **Ưu tiên cao nhất** - Nơi tập trung phát triển kỹ năng CP cốt lõi

## 📁 Cấu trúc

### 💻 `code/` - Templates & Solutions

-   **cpp/**: C++ templates và solutions (ngôn ngữ chính cho CP)
-   **python/**: Python backup templates
-   **java/**: Java cho contests đặc biệt
-   **javascript/**: JavaScript cho web development
-   **go/**: Go cho systems programming
-   **kotlin/**: Kotlin cho Android + competitive

### 📚 `theory/` - Lý thuyết & Tài liệu

#### `algorithms/` - Thuật toán phân loại chi tiết

-   **01-basic/**: Sorting, searching, two-pointers
-   **02-graph/**: DFS, BFS, shortest path, MST
-   **03-dp/**: Dynamic Programming
-   **04-greedy/**: Greedy algorithms
-   **05-string/**: KMP, Z-algorithm, suffix arrays
-   **06-math/**: Number theory, combinatorics
-   **07-advanced/**: Heavy-light decomposition, etc.

#### `data-structures/` - Cấu trúc dữ liệu theo độ khó

-   **01-linear/**: Array, stack, queue, deque
-   **02-trees/**: BST, heap, trie
-   **03-graphs/**: Adjacency list/matrix
-   **04-advanced/**: Segment tree, Fenwick tree

#### `mathematics/` - Toán CP chi tiết

-   **number-theory/**: Primes, GCD, modular arithmetic
-   **combinatorics/**: Permutations, combinations, DP
-   **geometry/**: Computational geometry
-   **probability/**: Probability & expected value

#### `techniques/` - Kỹ thuật giải toán

-   **problem-patterns/**: Nhận diện patterns
-   **complexity/**: Time/space analysis
-   **optimization/**: Code optimization techniques
-   **contest-strategy/**: Time management, debugging

### 🏃‍♂️ `practice/` - Luyện tập có hệ thống

#### `daily/` - Routine hàng ngày

-   **morning-warmup/**: 1-2 bài easy mỗi sáng
-   **evening-challenge/**: 1 bài medium/hard mỗi tối

#### `contests/` - Contest participation

-   **codeforces/**: CF contest solutions
-   **atcoder/**: AtCoder contest solutions
-   **leetcode/**: LeetCode weekly contests
-   **others/**: Other platforms

#### `by-rating/` - Phân loại theo rating (Focus progression)

-   **0800-1199-newbie/**: Green problems
-   **1200-1399-pupil/**: Blue problems
-   **1400-1599-specialist/**: Cyan problems
-   **1600-1899-expert/**: Blue problems
-   **1900-plus-master/**: Purple+ problems

#### `by-topic/` - Luyện tập theo chủ đề

-   **implementation/**: Pure implementation
-   **math/**: Mathematical problems
-   **greedy/**: Greedy approach
-   **dp/**: Dynamic programming
-   **graphs/**: Graph algorithms
-   **strings/**: String manipulation
-   **geometry/**: Geometry problems
-   **interactive/**: Interactive problems

## 🎯 Mục tiêu

1. **Xây dựng foundation vững chắc** về algorithms & data structures
2. **Phát triển problem-solving skills** qua practice có hệ thống
3. **Tăng rating** từ từ qua các levels
4. **Chuẩn bị cho contests** với templates và strategies

## 📊 Tracking Progress

-   Theo dõi rating progression qua các contests
-   Monitor topics đã master vs chưa
-   Time complexity analysis cho mỗi solution
-   Contest performance review

## 🚀 Getting Started

1. **Setup templates** trong `code/cpp/` cho daily practice
2. **Warm-up** với `practice/daily/morning-warmup/`
3. **Topic learning** theo sequence trong `theory/`
4. **Practice problems** theo rating trong `practice/by-rating/`
5. **Join contests** và review performance

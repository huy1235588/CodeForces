# JavaScript Template for Competitive Programming

## Execution

### Run:
```bash
node template.js
```

### With input file:
```bash
node template.js < input.txt
```

## Note
For online judges, create an `input.txt` file in the same directory for local testing.

## Features

- Fast I/O functions for reading different data types
- Mathematical utilities: GCD, LCM, Power, Prime checking
- Sieve of Eratosthenes
- Binary search implementation
- Graph algorithms: DFS, BFS
- Array utility functions

## Usage

1. Copy the template
2. Create `input.txt` file for local testing
3. Implement your algorithm in the solve() function
4. Run with Node.js

## Tips

- Use `readInt()` for single integer input
- Use `readInts()` for multiple integers input
- For multiple test cases, uncomment the loop in main()
- Use `Math.floor()` for integer division

# Python Template for Competitive Programming

## Execution

### Run:
```bash
python template.py
```

### With input file:
```bash
python template.py < input.txt
```

## Features

- Fast input functions
- Mathematical utilities: GCD, LCM, Power, Prime checking
- Sieve of Eratosthenes
- Binary search implementation
- Graph algorithms: DFS, BFS
- Common imports for competitive programming

## Usage

1. Copy the template
2. Implement your algorithm in the solve() function
3. Run the script

## Tips

- Use `fast_int()` for single integer input
- Use `fast_ints()` for multiple integers input
- For multiple test cases, uncomment the loop in main()
- Use `@lru_cache` for memoization

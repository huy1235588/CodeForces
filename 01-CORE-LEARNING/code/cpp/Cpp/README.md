# C++ Template for Competitive Programming

## Compilation and Execution

### Compile:
```bash
g++ -o solution template.cpp
```

### Run:
```bash
./solution
```

### With input file:
```bash
./solution < input.txt
```

## Features

- Fast I/O with `ios_base::sync_with_stdio(false)`
- Common macros and typedefs
- Utility functions: GCD, LCM, Power with modulo
- Vector printing function
- Constants: MOD, INF, LINF, EPS

## Usage

1. Copy the template
2. Implement your algorithm in the main function
3. Compile and run

## Tips

- Use `ll` for long long
- Use `pb` for push_back
- Use `all(x)` for x.begin(), x.end()
- Use `sz(x)` for size of container

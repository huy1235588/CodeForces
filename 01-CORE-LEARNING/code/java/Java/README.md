# Java Template for Competitive Programming

## Compilation and Execution

### Compile:
```bash
javac Solution.java
```

### Run:
```bash
java Solution
```

### With input file:
```bash
java Solution < input.txt
```

## Features

- Fast I/O with BufferedReader and PrintWriter
- FastScanner class for quick input parsing
- Utility functions: GCD, LCM, Power, Prime checking
- Sieve of Eratosthenes
- Binary search implementation
- Graph algorithms: DFS, BFS

## Usage

1. Copy the template
2. Implement your algorithm in the solve() method
3. Compile and run

## Tips

- Use FastScanner for all input operations
- Use FastPrinter for output (don't forget to close/flush)
- For multiple test cases, uncomment the loop in main()
- Arrays.sort() for primitive arrays, Collections.sort() for objects

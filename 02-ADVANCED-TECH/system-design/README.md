# 🏗️ System Design

Kiến thức về thiết kế hệ thống từ cơ bản đến nâng cao cho các hệ thống quy mô lớn.

## 📚 Nội dung học tập

### 🔧 Basics - Kiến thức cơ bản
- Nguyên lý thiết kế hệ thống
- Kiến trúc monolithic vs microservices
- Load balancing và reverse proxy
- API design và RESTful services
- Database sharding và replication

### 📈 Scalability - Khả năng mở rộng
- Horizontal vs Vertical scaling
- Content Delivery Networks (CDN)
- Database scaling strategies
- Caching strategies
- Asynchronous processing

### 🗃️ Databases - Cơ sở dữ liệu
- SQL vs NoSQL
- ACID properties
- CAP theorem
- Database indexing
- Transaction management
- Data warehousing

### 🔄 Microservices - Kiến trúc microservices
- Service decomposition
- Inter-service communication
- Service discovery
- Circuit breaker pattern
- Distributed transactions

### ⚡ Caching - Bộ nhớ đệm
- Cache patterns (Cache-aside, Write-through, Write-behind)
- Cache eviction policies
- Distributed caching
- Redis và Memcached
- CDN caching

### 📨 Messaging - Hệ thống tin nhắn
- Message queues
- Publish-Subscribe pattern
- Event-driven architecture
- Apache Kafka, RabbitMQ
- Stream processing

### 🔒 Security - Bảo mật
- Authentication vs Authorization
- OAuth 2.0 và JWT
- HTTPS và TLS
- API security
- Data encryption
- Security best practices

### 🎨 Design Patterns - Mẫu thiết kế
- Singleton, Factory, Observer
- Repository pattern
- Command pattern
- Strategy pattern
- Decorator pattern

## 🎯 Mục tiêu học tập
- Hiểu được các nguyên lý thiết kế hệ thống
- Có thể thiết kế hệ thống có khả năng mở rộng
- Nắm vững các pattern và best practices
- Chuẩn bị cho phỏng vấn system design

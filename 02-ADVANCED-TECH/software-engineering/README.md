# 💼 Software Engineering

Thực hành kỹ thuật phần mềm chuyên nghiệp và quy trình phát triển hiện đại.

- Naming conventions
- Function và class design
- Comments và documentation
- Code formatting
- SOLID principles
- DRY, KISS, YAGNI
- Code smells và refactoring

### 🧪 Testing - Kiểm thử phần mềm
- Unit testing fundamentals
- Test-Driven Development (TDD)
- Behavior-Driven Development (BDD)
- Integration testing
- End-to-end testing
- Test automation
- Code coverage

### 🔄 Refactoring - Tái cấu trúc code
- Refactoring techniques
- Code metrics
- Technical debt management
- Legacy code handling
- Automated refactoring tools
- Safe refactoring practices

### 🌳 Version Control - Quản lý phiên bản

- Branching strategies (Git Flow, GitHub Flow)
- Merge vs Rebase
- Conflict resolution
- Code collaboration
- Semantic versioning
- Conventional commits

### 👀 Code Review - Đánh giá code
- Code review process
- Review checklist
- Constructive feedback
- Tools và platforms
- Security code review
- Performance review
- Best practices

### 📝 Documentation - Tài liệu hóa
- Technical writing
- API documentation
- Code documentation
- Architecture documentation
- User guides
- README best practices
- Documentation tools

## 🎯 Mục tiêu học tập
- Viết code chất lượng cao, dễ bảo trì
- Áp dụng các best practices trong phát triển
- Làm việc hiệu quả trong team
- Tự động hóa quy trình phát triển

- **Version Control**: Git, GitHub, GitLab

- **CI/CD**: GitHub Actions, Jenkins, GitLab CI

## 📈 Lộ trình học tập

### Giai đoạn 1: Nền tảng (1-2 tháng)
- [ ] Cấu trúc dữ liệu cơ bản (Array, String, Stack, Queue)
- [ ] Thuật toán tìm kiếm và sắp xếp
- [ ] Kỹ thuật Two Pointers và Sliding Window
- [ ] Độ phức tạp thuật toán (Big O)

### Giai đoạn 2: Trung cấp (2-3 tháng)
- [ ] Cấu trúc dữ liệu nâng cao (Tree, Heap, Hash Table)
- [ ] Thuật toán đồ thị cơ bản (DFS, BFS, Dijkstra)
- [ ] Quy hoạch động cơ bản
- [ ] Thuật toán tham lam

### Giai đoạn 3: Nâng cao (3-4 tháng)
- [ ] Cấu trúc dữ liệu chuyên sâu (Segment Tree, Fenwick Tree)
- [ ] Thuật toán đồ thị nâng cao (MST, Network Flow)
- [ ] Quy hoạch động nâng cao
- [ ] Thuật toán xử lý chuỗi

### Giai đoạn 4: Chuyên gia (4+ tháng)
- [ ] Toán học nâng cao (Number Theory, Combinatorics)
- [ ] Hình học tính toán
- [ ] Thuật toán tối ưu hóa
- [ ] Cấu trúc dữ liệu persistent

### Templates có sẵn
Tất cả templates bao gồm:

- ✅ Common mathematical functions (GCD, LCM, Power, Factorial)

### Language-Specific Optimizations

#### C++ (`/code/Cpp/`)
- Optimized với `ios_base::sync_with_stdio(false)`
- Includes `bits/stdc++.h` header
- Common macros cho competitive programming
- Template classes cho common data structures

#### Python (`/code/Python/`)
- Fast input functions sử dụng `sys.stdin`
- Comprehensive utility functions
- Support cho multiple test cases
- Memory-efficient implementations

#### Java (`/code/Java/`)
- BufferedReader/PrintWriter cho fast I/O
- FastScanner class cho efficient parsing
- Memory-optimized implementations
- Common algorithms và data structures

#### JavaScript (`/code/Javascript/`)
- File-based input reading với Node.js
- Built-in utility functions
- ES6+ features được utilize
- Async/await support cho I/O operations

#### Go (`/code/Go/`)
- Buffered I/O với proper flushing
- Type-safe implementations
- Efficient memory usage
- Concurrent programming utilities

#### Kotlin (`/code/Kotlin/`)
- Extension functions cho cleaner code
- Java interoperability
- Modern language features
- Functional programming utilities

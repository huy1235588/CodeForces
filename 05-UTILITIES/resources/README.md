# 📚 Learning Resources

## Tổng quan
Danh sách tài nguyên học tập chất lượng cao cho lập trình thi đấu, bao gồm sách, khóa học online, website và công cụ hỗ trợ.

## 📖 Books (Sách)

### Beginner Level
1. **"Competitive Programming 4" by Steven & Felix Halim**
   - Comprehensive guide cho competitive programming
   - Covers algorithms, data structures, mathematics
   - Includes practice problems và solutions
   - Best for: Complete beginners to intermediate

2. **"Guide to Competitive Programming" by Antti Laaksonen**
   - Based on author's experience in IOI và ICPC
   - Clear explanations với practical examples
   - Covers C++ STL extensively
   - Best for: Beginners who prefer concise content

3. **"Programming Pearls" by Jon Bentley**
   - Classic book on problem-solving techniques
   - Focus on algorithm design và optimization
   - Real-world programming wisdom
   - Best for: Understanding problem-solving mindset

### Intermediate Level
4. **"Introduction to Algorithms (CLRS)" by Cormen et al.**
   - Comprehensive algorithms textbook
   - Theoretical foundation với rigorous proofs
   - Essential reference for advanced topics
   - Best for: Deep understanding of algorithms

5. **"Algorithm Design" by Jon Kleinberg & Éva Tardos**
   - Focus on algorithm design techniques
   - Excellent problem sets
   - Clear explanations of complex topics
   - Best for: Learning to design algorithms

6. **"Competitive Programmer's Handbook" by Antti Laaksonen**
   - Free online book
   - Practical guide với code examples
   - Covers most CP topics concisely
   - Best for: Quick reference và learning

### Advanced Level
7. **"The Art of Computer Programming" by Donald Knuth**
   - The ultimate reference for algorithms
   - Mathematical rigor và comprehensive coverage
   - Multiple volumes covering different topics
   - Best for: Advanced practitioners và research

8. **"Concrete Mathematics" by Graham, Knuth & Patashnik**
   - Mathematical foundations for computer science
   - Essential for advanced mathematical problems
   - Covers discrete math comprehensively
   - Best for: Strong mathematical background needed

### Specialized Topics
9. **"Computational Geometry: Algorithms and Applications"**
   - Comprehensive guide to computational geometry
   - Theoretical foundation với practical algorithms
   - Best for: Geometry-heavy contests

10. **"Network Flows: Theory, Algorithms, and Applications"**
    - Deep dive into flow algorithms
    - Advanced graph theory
    - Best for: Advanced graph problems

## 🏆 Getting Started Guide

### For Complete Beginners
1. Start với **"Guide to Competitive Programming"**
2. Practice on **AtCoder Beginner Contests**
3. Watch **Abdul Bari** for algorithm basics
4. Use **CSES Problem Set** for systematic practice

### For Intermediate Learners
1. Read **"Competitive Programming 4"**
2. Practice on **Codeforces** (rating 1200-1600)
3. Follow **Errichto** for advanced techniques
4. Study **CP-Algorithms** for specific topics

### For Advanced Practitioners
1. Reference **"Introduction to Algorithms (CLRS)"**
2. Participate in **Div 1 contests**
3. Read research papers for cutting-edge algorithms
4. Contribute to open-source algorithm libraries

## 💡 Study Tips

1. **Mix theory và practice**: Don't just read, implement algorithms
2. **Track progress**: Maintain learning journal
3. **Join community**: Engage với other learners
4. **Teach others**: Best way to solidify understanding
5. **Be patient**: Competitive programming takes time to master
6. **Focus on understanding**: Don't just memorize solutions

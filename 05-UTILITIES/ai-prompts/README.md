# 🤖 AI Prompts Collection

## Tổng quan
Bộ sưu tập các prompt AI được thiết kế đặc biệt để hỗ trợ học thuật toán và lập trình thi đấu. Các prompt này được tối ưu hóa để tìm kiếm tài liệu, phân tích code, và giải quyết vấn đề một cách hiệu quả.

## 📁 Cấu trúc thư mục

### 🔍 `research` - Prompts tìm kiếm và nghiên cứu
- **Algorithm Research**: Tìm hiểu thuật toán mới
- **Paper Search**: Tìm kiếm nghiên cứu khoa học
- **Documentation Search**: Tìm tài liệu kỹ thuật
- **Tutorial Discovery**: Khám phá tutorial chất lượng

### 📚 `learning` - Prompts học tập
- **Concept Explanation**: Giải thích khái niệm
- **Example Generation**: Tạo ví dụ minh họa
- **Practice Problem**: Tìm bài tập phù hợp
- **Learning Path**: Xây dựng lộ trình học

### 🧩 `problem-solving` - Prompts giải bài toán
- **Problem Analysis**: Phân tích đề bài
- **Approach Selection**: Chọn phương pháp giải
- **Optimization**: Tối ưu hóa giải pháp
- **Debug Assistance**: Hỗ trợ debug

### 🔬 `code-analysis` - Prompts phân tích code
- **Code Review**: Đánh giá chất lượng code
- **Complexity Analysis**: Phân tích độ phức tạp
- **Bug Detection**: Tìm lỗi trong code
- **Code Optimization**: Tối ưu hóa code

## 🎯 Cách sử dụng

### 1. Chọn prompt phù hợp
- Xác định mục tiêu (research, learning, solving, analysis)
- Chọn prompt template từ thư mục tương ứng
- Customize prompt theo nhu cầu cụ thể

### 2. Điều chỉnh context
- Thêm thông tin về level hiện tại
- Specify ngôn ngữ lập trình
- Đưa vào constraints cụ thể

### 3. Optimize kết quả
- Sử dụng follow-up questions
- Yêu cầu ví dụ cụ thể
- Ask for multiple approaches

## 🌟 Best Practices

### Prompt Engineering Tips
1. **Be Specific**: Càng cụ thể càng tốt
2. **Provide Context**: Đưa thông tin về background
3. **Set Constraints**: Giới hạn scope và format
4. **Ask for Examples**: Yêu cầu ví dụ minh họa
5. **Iterate**: Cải thiện prompt qua nhiều lần sử dụng

### Common Patterns
- **Role-based**: "Act as an algorithm expert..."
- **Task-specific**: "Help me understand..."
- **Format-driven**: "Provide a step-by-step..."
- **Example-driven**: "Show me examples of..."

## 🔧 Template Variables

### Skill Level Variables
- `{SKILL_LEVEL}`: beginner, intermediate, advanced, expert
- `{RATING}`: current competitive programming rating
- `{EXPERIENCE}`: years of programming experience

### Technical Variables
- `{LANGUAGE}`: C++, Python, Java, etc.
- `{TOPIC}`: specific algorithm or data structure
- `{COMPLEXITY}`: time/space complexity requirements
- `{PLATFORM}`: Codeforces, AtCoder, LeetCode, etc.

### Context Variables
- `{PROBLEM_TYPE}`: DP, Graph, String, Math, etc.
- `{DIFFICULTY}`: easy, medium, hard
- `{TIME_LIMIT}`: available time for learning/solving
- `{GOAL}`: specific learning objective

## 📈 Effectiveness Tracking

### Metrics to Monitor
1. **Response Quality**: Relevance và accuracy của answers
2. **Time Saved**: Thời gian tiết kiệm được
3. **Learning Progress**: Improvement in understanding
4. **Problem Solving**: Success rate in contests

### Feedback Loop
- Rate prompt effectiveness (1-5 stars)
- Note what worked well
- Identify areas for improvement
- Share successful prompts with community

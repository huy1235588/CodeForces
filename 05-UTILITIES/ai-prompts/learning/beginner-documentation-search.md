# 🔍 Prompt Tìm Kiếm Tài Liệu Chi Tiết Cho Người Mới Bắt Đầu

## 📋 Prompt Tổng Hợp Tìm Kiếm Tài Liệu

```
Tôi cần tìm toàn bộ tài liệu chi tiết cho người mới bắt đầu học Competitive Programming.
Hãy tìm kiếm và tổng hợp từ các nguồn sau trong workspace:

1. **HƯỚNG DẪN KHỞI ĐẦU:**
   - File QUICK_START.md (hướng dẫn 5 phút đầu)
   - File README.md gốc (tổng quan toàn bộ workspace)
   - Folder 01-CORE-LEARNING/README.md (cấu trúc học tập)

2. **TÀI LIỆU LÝ THUYẾT CƠ BẢN:**
   - 01-CORE-LEARNING/theory/algorithms/01-basic/ (thuật toán cơ bản)
   - 01-CORE-LEARNING/theory/data-structures/01-linear/ (cấu trúc dữ liệu tuyến tính)
   - 01-CORE-LEARNING/theory/techniques/problem-patterns/ (patterns nhận diện bài toán)
   - 01-CORE-LEARNING/theory/mathematics/number-theory/ (toán cơ bản)

3. **TEMPLATE VÀ CODE MẪU:**
   - 01-CORE-LEARNING/code/cpp/template.cpp (template C++ chính)
   - 01-CORE-LEARNING/code/cpp/ (các solution mẫu)

4. **LUYỆN TẬP THEO HỆ THỐNG:**
   - 01-CORE-LEARNING/practice/by-rating/ (phân loại theo độ khó)
   - 01-CORE-LEARNING/practice/by-topic/ (phân loại theo chủ đề)
   - 01-CORE-LEARNING/practice/daily/ (routine hàng ngày)

5. **TÀI LIỆU THAM KHẢO:**
   - 05-UTILITIES/resources/ (sách, khóa học, websites)
   - 04-CAREER/interview-prep/coding-interviews/ (chuẩn bị phỏng vấn)

Yêu cầu output:
- Liệt kê đầy đủ các file tài liệu có sẵn
- Tóm tắt nội dung chính của từng phần
- Đề xuất roadmap học tập 30 ngày đầu
- Checklist các bước setup môi trường
- Danh sách 10 bài toán đầu tiên nên làm
```

## 📌 Tips Tối Ưu Hóa Tìm Kiếm

-   **Specific keywords**: Sử dụng từ khóa cụ thể như "beginner", "basic", "01-", "README"
-   **File extensions**: Tìm .md, .cpp, .txt files
-   **Folder hierarchy**: Ưu tiên 01-CORE-LEARNING → theory → algorithms/data-structures
-   **Progressive search**: Bắt đầu từ tổng quan → chi tiết → practice
-   **Cross-reference**: Liên kết giữa theory và practice problems

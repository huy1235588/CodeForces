# 📚 Learning Support Prompts

## 1. Concept Explanation

```
Act as a patient và expert computer science tutor specialized trong competitive programming.

I need help understanding {CONCEPT_NAME}. 

My background:
- Current skill level: {SKILL_LEVEL}
- Programming experience: {EXPERIENCE_YEARS} years
- Familiar concepts: {KNOWN_CONCEPTS}
- Learning goal: {SPECIFIC_GOAL}

Please explain this concept using:

1. **Simple Analogy**:
   - Real-world analogy to make it intuitive
   - Step-by-step comparison
   - Why this analogy works

2. **Technical Definition**:
   - Formal definition trong computer science terms
   - Key properties và characteristics
   - Relationship to other concepts

3. **Visual Explanation**:
   - Describe what it would look like if visualized
   - Step-by-step process breakdown
   - Common visual representations

4. **Code Example**:
   - Simple implementation trong {LANGUAGE}
   - Line-by-line explanation
   - Common variations

5. **Practice Application**:
   - Where this concept appears trong contests
   - Recognition patterns
   - Simple practice problems

Use clear language, build from basics, và check understanding at each step.
```

## 2. Example Generation

```
I'm learning {TOPIC} và need diverse examples to solidify my understanding.

Requirements:
- Skill level: {SKILL_LEVEL}
- Focus area: {SPECIFIC_FOCUS}
- Programming language: {LANGUAGE}
- Example count: {NUMBER} examples

Generate examples that cover:

1. **Basic Examples**:
   - Simplest possible case
   - Clear input/output
   - Step-by-step solution walkthrough
   - Common beginner mistakes to avoid

2. **Intermediate Examples**:
   - More complex scenarios
   - Multiple solution approaches
   - Optimization opportunities
   - Edge case handling

3. **Advanced Examples** (if applicable):
   - Complex constraints
   - Multiple techniques combined
   - Real contest problem style
   - Time/space optimization needed

4. **Edge Cases**:
   - Boundary conditions
   - Special input cases
   - Error conditions
   - Performance limits

For each example, provide:
- Problem statement
- Sample input/output
- Solution approach explanation
- Complete code implementation
- Complexity analysis
- Alternative approaches (if any)
```

## 3. Practice Problem Curation

```
I need practice problems for {TOPIC} that match my current skill level và learning objectives.

My profile:
- Current rating: {RATING}
- Skill level: {SKILL_LEVEL}
- Weak areas: {WEAKNESS_LIST}
- Strong areas: {STRENGTH_LIST}
- Available practice time: {TIME_AVAILABLE}
- Preferred platforms: {PLATFORM_LIST}

Please curate a practice set với:

1. **Foundational Problems** (30%):
   - Core concept application
   - Standard implementations
   - Build confidence và familiarity

2. **Skill Building Problems** (50%):
   - Slightly challenging variations
   - Combine multiple concepts
   - Common contest patterns

3. **Stretch Problems** (20%):
   - Push current limits
   - Advanced applications
   - Prepare for next level

For each problem, provide:
- Problem name và source link
- Difficulty estimate (1-10)
- Key concepts tested
- Expected solve time
- Hints for getting started
- Related problems for follow-up

Organize by priority và include a suggested solving order.
```

## 4. Learning Path Creation

```
Create a comprehensive learning path for mastering {TOPIC_AREA} trong competitive programming context.

My current situation:
- Skill level: {SKILL_LEVEL}
- Available time: {HOURS_PER_WEEK} hours/week
- Learning timeline: {TARGET_TIMELINE}
- Specific goals: {GOALS_LIST}
- Preferred learning style: {LEARNING_STYLE}

Design a path that includes:

1. **Prerequisites Assessment**:
   - Required background knowledge
   - Skills that should be solid first
   - Recommended preparation time

2. **Core Learning Modules**:
   - Module breakdown với learning objectives
   - Estimated time for each module
   - Key concepts và skills for each
   - Success criteria

3. **Practice Integration**:
   - Practice problems for each module
   - Mini-projects hoặc applications
   - Self-assessment checkpoints

4. **Progress Milestones**:
   - Weekly/monthly goals
   - Skill checkpoints
   - Assessment methods
   - Adjustment triggers

5. **Resource Recommendations**:
   - Best tutorials for each topic
   - Reference materials
   - Community resources
   - Practice platforms

6. **Common Pitfalls**:
   - Typical learning obstacles
   - How to overcome them
   - When to seek help
   - Signs of progress

Make the path actionable với specific next steps và measurable progress indicators.
```

## 5. Concept Connection Map

```
Help me understand how {CONCEPT_A} relates to other concepts trong competitive programming.

I want to build a mental model that shows:

1. **Direct Dependencies**:
   - What concepts I need to know first
   - Prerequisites và foundations
   - Building block relationships

2. **Related Concepts**:
   - Similar algorithms hoặc techniques
   - Alternative approaches
   - Complementary skills

3. **Advanced Extensions**:
   - How this concept leads to advanced topics
   - Optimization techniques
   - Specialized variations

4. **Application Domains**:
   - Types of problems where this appears
   - Common problem patterns
   - Contest categories

5. **Learning Sequence**:
   - Optimal order to learn related concepts
   - Which to study together
   - Which to postpone until later

6. **Practice Strategy**:
   - How to practice these connections
   - Problems that combine multiple concepts
   - Skill transfer opportunities

Present this as a visual concept map với explanations of each connection và practical learning advice.
```

## 6. Difficulty Progression

```
I've mastered {CURRENT_TOPIC} at a basic level và want to progressively increase difficulty.

Current status:
- Can solve: {CURRENT_PROBLEM_TYPES}
- Struggle with: {DIFFICULTY_AREAS}
- Success rate: {SUCCESS_PERCENTAGE}% on {DIFFICULTY_LEVEL} problems
- Average solve time: {SOLVE_TIME}

Design a progression plan:

1. **Current Level Assessment**:
   - Strengths trong current implementations
   - Gaps trong understanding
   - Speed và accuracy metrics

2. **Next Level Targets**:
   - Specific skills to develop
   - Problem types to master
   - Performance improvements needed

3. **Progression Steps**:
   - Intermediate challenges
   - Skill-building exercises
   - Complexity increases

4. **Practice Structure**:
   - Daily/weekly practice goals
   - Mix of review và new challenges
   - Difficulty escalation timeline

5. **Mastery Indicators**:
   - How to know when ready for next level
   - Self-assessment criteria
   - Performance benchmarks

6. **Adjustment Strategies**:
   - What to do if stuck
   - When to step back vs push forward
   - Alternative learning approaches

Include specific problem recommendations và a timeline for progression.
```

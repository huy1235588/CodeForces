# 🔍 Algorithm Research Prompts

## 1. Deep Algorithm Research

```
Act as an expert competitive programming coach với extensive knowledge về algorithms và data structures.

I want to research về {ALGORITHM_NAME}. My current skill level là {SKILL_LEVEL} và I'm preparing for {PLATFORM} contests.

Please provide:

1. **Comprehensive Overview**:
   - Algorithm definition và core concepts
   - Time và space complexity analysis
   - When to use this algorithm (problem characteristics)

2. **Implementation Details**:
   - Step-by-step algorithm explanation
   - Common implementation patterns trong {LANGUAGE}
   - Edge cases và error handling

3. **Applications & Variations**:
   - Classic problems that use this algorithm
   - Variations và optimizations
   - Related algorithms và techniques

4. **Learning Resources**:
   - Best tutorials và explanations
   - Practice problems (sorted by difficulty)
   - Reference implementations

5. **Contest Applications**:
   - How to recognize when to use this algorithm
   - Common contest problem patterns
   - Time-saving implementation tips

Format: Provide detailed explanations với code examples. Include complexity analysis và practical tips.
```
